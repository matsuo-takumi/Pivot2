# 💻 Tech Stack

このドキュメントでは、Pivotプロジェクトで使用される主要な技術スタックとその選択理由について説明します。

## 1. Programming Languages and Versions

- **C# (.NET 8)**:
  - **理由**: Windowsデスクトップアプリケーション開発における堅牢性、パフォーマンス、豊富なライブラリエコシステム。WinUI 3とのネイティブな統合。

## 2. Frameworks and Libraries

- **WinUI 3 (Windows App SDK)**:
  - **理由**: 最新のWindowsアプリケーションUIフレームワーク。Fluent Design Systemのサポート、高いパフォーマンス、Windowsプラットフォームとの深い統合。
- **MVVM (Model-View-ViewModel)**:
  - **理由**: UIとビジネスロジックの明確な分離を提供し、テスト容易性、保守性、拡張性を向上させます。
- **Microsoft.Extensions.DependencyInjection** (または類似のDIコンテナ):
  - **理由**: 依存性注入を実装し、コンポーネント間の結合度を低減。モジュール性、テスト容易性、保守性を向上させます。
- **SQLite / LiteDB**:
  - **理由**: ローカルデータ永続化のための軽量で高性能な組み込みデータベース。SQLiteは広範なサポートと信頼性があり、LiteDBはNoSQLの柔軟性を提供します。
- **ONNX Runtime**:
  - **理由**: AIモデル（CLIP / EfficientNet）の高速な推論実行を可能にするクロスプラットフォームライブラリ。
- **Serilog**:
  - **理由**: 柔軟で構成可能なログフレームワーク。構造化ロギングをサポートし、問題のデバッグと監視を容易にします。
- **AvalonEdit (推奨)**:
  - **理由**: スクリプトエディタ機能の構文ハイライトとカスタマイズ性を提供します。
- **Win2D**:
  - **理由**: Canvas機能の実現に必要なグラフィックライブラリ。高性能な2Dグラフィック描画をサポートします。

## 3. Build Tools and Package Managers

- **.NET CLI / MSBuild**:
  - **理由**: C#プロジェクトの標準ビルドツール。クロスプラットフォーム開発と統合されたビルドプロセスを提供します。
- **NuGet**:
  - **理由**: .NETエコシステムにおける標準パッケージマネージャー。ライブラリの依存関係管理と配布を簡素化します。
- **MSIX**:
  - **理由**: Windowsアプリケーションの最新のパッケージングおよびデプロイ技術。クリーンなインストール/アンインストール、自動更新、セキュリティ機能を提供します。

## 4. CI/CD Configuration Tools

- (将来的にGitHub ActionsやAzure DevOpsを検討予定)
  - **理由**: 自動化されたビルド、テスト、デプロイメントパイプラインを構築し、開発プロセスを効率化するため。

## 5. Testing Frameworks and Coverage Goals

- **MSTest / NUnit / xUnit** (いずれかを検討):
  - **理由**: .NETアプリケーションの単体テスト、統合テストをサポートするための標準的なテストフレームワーク。
- **カバレッジ目標**: 主要なビジネスロジックおよびサービス層で80%以上のコードカバレッジを目指します。

## 6. Hosting/Infrastructure Setup

- **ローカルデスクトップアプリケーション**:
  - **理由**: 主要なデプロイメントターゲット。Windows 10/11 (x64, ARM64) 環境でのネイティブ実行を想定。
- **クラウド同期 (将来的な検討)**:
  - **理由**: `SyncService` を介したWeb API連携により、プロジェクト情報やWIP情報のクラウド同期をサポート。バックエンドサービスはAzure FunctionsやAWS LambdaなどのFaaS、またはASP.NET Core Web APIを検討。

## 7. Justification for Selected Technologies

- **生産性**: C#と.NETエコシステムは、IDE (Visual Studio, Cursor) との統合が強力で、高い開発生産性を提供します。
- **パフォーマンス**: WinUI 3とC#の組み合わせは、ネイティブに近いパフォーマンスを発揮し、大規模なアセット管理アプリケーションに求められる応答性を実現します。
- **拡張性**: MVVM、DI、プラグインアーキテクチャの採用により、将来的な機能拡張やDCCツール連携に柔軟に対応できます。
- **AI連携**: ONNX Runtimeの採用により、最新のAIモデルをアプリケーションに統合し、アセット管理の知能化を実現します。
- **保守性**: 強力な型付け言語C#と、明確なアーキテクチャパターンにより、長期的な保守性とコード品質を維持します。
