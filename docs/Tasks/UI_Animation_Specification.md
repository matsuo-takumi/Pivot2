# 🎨 UI/UX Animation & Interaction Specification

PivotアプリケーションのUIにおけるアニメーションおよびユーザーインタラクションの概要（現状と指針）を以下に示します。

## 1. アニメーション概要

| カテゴリ       | 要素             | 挙動/詳細                                 | 実装/補足                               |
| -------------- | ---------------- | --------------------------------------- | ------------------------------------- |
| **ナビゲーション** | トップレベルタブ移動 | WinUI 3 デフォルト (左右スライド)         | `CommonNavigationTransitionInfo.Slide` 相当  |
|                | 設定ページ遷移   | 下からスライドイン (縦方向)               | `EntranceNavigationTransitionInfo`    |
|                | Pane 開閉        | WinUI 3 デフォルト (スムーズなスライド)   | `NavigationView.IsPaneOpen` による制御 |
| **コントロール** | デフォルト挙動   | ホバー、プレス、選択時の視覚フィードバック | WinUI 3 デフォルトスタイル            |
|                | カスタム         | なし                                    |                                       |
| **アイコン**     | すべて           | 静的                                    | `SymbolIcon`/`FontIcon`。アニメーションなし。|

## 2. 全体方針 (Fluent Design System の原則に準拠)

*   **応答性**: ユーザー操作への即座の反応。UIブロックの回避。
*   **明示性**: アニメーションは意図伝達のためのみ。不必要な装飾は回避。
*   **一貫性**: アプリケーション全体でのスタイルとタイミング統一。
*   **機能的アニメーション**: 視覚的楽しさだけでなく、機能的意味を持つアニメーションを優先。
*   **パフォーマンス**: 低スペック環境でもスムーズに動作。
